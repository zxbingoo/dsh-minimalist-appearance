# dsh-minimalist-appearance

外观 / Appearance

DSH 持久化外观插件。新增左侧「外观」入口，只覆盖颜色与对话背景，不改变原有字体、字号、字重、行高、间距、控件尺寸、消息结构或交互。

## 使用

1. 打开左侧「外观」。
2. 设置页按参考图分为上方 2:1 大预览、下方「全部主题」紧凑缩略图。常规宽度为五列，名称在缩略图下方，选中项使用主文字色双层轮廓；窄面板自动减为三列或两列。不复制参考图的设置侧栏。
3. 点击「浅色、深色、跟随系统、绿色、海蓝、暖沙、原始」任一主题，上方示意立即更新，并以一次原子写入应用及保存；不再设置分组、长说明、独立保存页脚或跳转真实对话的预览按钮。保存中暂时禁止重复点击；失败保留选择，可再次点击同一主题重试。
   - 「绿色」（原名「有风」）保留既有灰绿色侧栏、水彩壁纸和已修复的组件配色，内部 `breeze` / `forest` 标识不变。
   - 「原始」同样点击即应用，移除插件的颜色与背景覆盖，不修改原生 DSH 的主题、字体或布局偏好，也不删除旧配置中的休眠图片。
4. 大预览是设置页内的静态外观示意，不是第二个真实会话，也不能输入或发送消息；布局和裁切不保证与原生对话一致。缩略图及示意共用真实背景的图片、配色、fade 和 cover 绘制规则；基础主题缩略图用静态窗口骨架，系统主题左右展示浅深色。原始主题使用注册主题颜色和中性色回退，不冒充像素级真实渲染。
5. 只读或离线时点击仅改变本页示意，不应用或保存，并显示「仅预览 · 未应用」。重连不会自动保存或重启临时覆盖，需再次点击主题；进行中的保存由插件持有，切换面板后仍可结算。关闭或刷新页面会清除未保存的内存选择。
6. 若设置在其他位置更新，未修改的选择会同步；已有修改则保留并锁定选择，点击提示中的「重新载入」明确丢弃旧选择后继续。当前版本仍不提供任何自定义颜色、上传、背景或淡化控件。

各预设固定其配色、明暗和背景组合，不修改 DSH 原生主题偏好。浅/深色基础配色是本插件的中性色方案，不保证与原生 DSH 逐像素相同；「原始」不应用任何颜色或背景覆盖，也是首次安装默认状态。旧版本保存的自定义值继续可读和生效，不进行破坏性迁移；只有明确选择并保存预设时才替换当前外观。

## 图片与隐私

- 当前配置页不提供上传和图片清理。为兼容旧配置，Host/Agent 校验仍只接受 PNG、JPEG、WebP，最大 2 MiB（原始解码字节），拒绝 SVG、远程 URL、错误 MIME/文件签名及超限数据。
- 旧背景以内联 data URL 保存在 profile 设置中，不请求外部图片服务；选择预设不会清除休眠图片。配置、备份或可读该 profile 的用户仍可获得图片。
- 「绿色」为参考配色与构图重新创作的内置水彩 PNG，不是参考应用截图；海蓝、暖沙和调色板图标为原创 SVG。随本插件提供，不含远程资源。
- 内置 PNG 在构建时校验签名并限制为 4 MiB，内联进 Client；它不写入 profile 图片字段，也不占用用户上传图片的 2 MiB 限额。

## Agent 操作

`dsh_appearance` 提供 `get / set / reset`，与页面共享 Host `settings.mutate` 操作及校验。`get` 返回 revision，`set/reset` 可附 `expectedRevision` 拒绝过期写入。返回值只包含图片 MIME 与字节数，不包含图片正文。为保持兼容，工具仍支持旧自定义字段；当前配置页只选择预设，不再提供上传。

## 已知限制

通用 settings 编辑器可以暂存「上传背景但未提供图片」的不完整组合；专用页面和 Agent 工具均拒绝这样保存。Client 对不完整配置不应用任何视觉覆盖，并提供恢复入口。

样式使用主题 tokens，补齐已核实的中性色文字、边框和交互底色。针对既有界面的 CSS 仅改绘制：完整对话框架背景及正文/滚动/输入区座位的透明底色，文件变更、交付文件卡和附件按钮的局部填充变量，共享弹出菜单的材质/图标/分组标题颜色变量，品牌标牌的局部反色文字，以及 macOS 侧栏的不透明底色（避免原生半透明材质将浅灰绿混成灰色）。不修改布局、字体或原生主题偏好。

背景接入点按 DSH 0.2.1-rc.5 的结构核实：完整对话框架使用 `div[data-phase]:has([data-conversation-content])`，输入座位使用 `[data-composer-seat]`；文件变更与交付文件卡使用原生 `[data-changed-files]` / `[data-presented-file]` 挂钩。共享弹出菜单按 MenuSurface 的 `[data-menu-material]` 挂钩重绑颜色，不限定菜单必须是输入框后代，也不按本地化标签、role 或散列类名猜测归属。macOS 侧栏仍按 AppFrame 含直接 `[data-shell-overlay]` 子元素的框架的第一个 `div` 定位，不使用散列类名；「原始」及仅改强调色时不覆盖原生侧栏材质。升级 DSH 后若结构变化，需要重新核对。设置页/对话真实预览的视觉效果仍需在已认证的实际页面中验证；单元测试和 Client 注册不代表视觉验收。
